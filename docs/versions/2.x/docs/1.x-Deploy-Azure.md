# Deploy: Azure (AKS)

> **Not yet checked for 2.x.** This page was written for chart 1.x. Its storage and TLS steps may still apply, but nobody has checked them against the 2.x chart. For 2.x, start with [Deploy: Core](./Deploy-Core).

Work through [Deploy: Core](./1.x-Deploy-Core) alongside this guide. The steps here are the Azure-specific additions to your `values.yaml` and the extra secrets to create beforehand.


## 1. Storage

The FN uses an Azure Storage Account file share to persist task results. **The file share must already exist before deploying.**

Create a Kubernetes secret with your storage account credentials:

```sh
kubectl create secret generic fn-azure-storage \
    --from-literal=azurestorageaccountkey="<your-storage-account-key>" \
    --from-literal=azurestorageaccountname="<your-storage-account-name>" \
    -n federated-node
```

Or via YAML (values must be base64-encoded):

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: fn-azure-storage
  namespace: federated-node
data:
  azurestorageaccountkey: <base64-encoded-key>
  azurestorageaccountname: <base64-encoded-name>
type: Opaque
```


## 2. TLS auto-renewal (optional)

If you want automatic SSL certificate renewal via an Azure Service Principal, you need a secret and a ConfigMap.

**Create the SP secret:**

```sh
kubectl create secret generic fn-azure-ssl-sp \
    --from-literal=SP_SECRET="<your-service-principal-secret>" \
    -n federated-node
```

**Create the ConfigMap** with your Azure subscription details:

```yaml
kind: ConfigMap
apiVersion: v1
metadata:
  name: fn-azure-ssl-config
  namespace: federated-node
data:
  EMAIL_CERT: admin@your-institution.example.com
  HOSTED_ZONE: your-institution.example.com
  RG_NAME: your-resource-group
  SP_ID: your-service-principal-app-id
  SUBSCRIPTION_ID: your-subscription-id
  TENANT_ID: your-tenant-id
```

```sh
kubectl apply -f fn-azure-ssl-config.yaml
```


## 3. Add the Azure block to values.yaml

Add this to your `values.yaml` (created in the core guide):

```yaml
on_aks: true

storage:
  azure:
    secretName: fn-azure-storage
    shareName: files
```

With TLS auto-renewal:

```yaml
on_aks: true

storage:
  azure:
    secretName: fn-azure-storage
    shareName: files

cert-manager:
  enabled: true

certs:
  azure:
    configmap: fn-azure-ssl-config
    secretName: fn-azure-ssl-sp
```

**If you are also deploying the Task Controller** (outbound mode), use a YAML anchor to avoid duplicating the storage config - the Task Controller needs the same storage secret:

```yaml
on_aks: true

storage: &storage
  azure:
    secretName: fn-azure-storage
    shareName: files

cert-manager:
  enabled: true

certs:
  azure:
    configmap: fn-azure-ssl-config
    secretName: fn-azure-ssl-sp

fn-task-controller:
  storage: *storage
```


## 4. Deploy

Return to [Deploy: Core](./1.x-Deploy-Core) step 8 and run `helm install` with your completed `values.yaml`.
