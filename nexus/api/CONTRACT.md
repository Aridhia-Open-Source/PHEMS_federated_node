# nexus/api contract with the UI (nexus/ui)

Same wire contract as the Flask webserver. Read from `origin/nexus/api`.

## Errors
- Every error body is `{"error": "<message>"}`, plus `"details"` when the error carries extra fields
  (e.g. a 409 on deleting a linked global resource lists `[{"id", "name"}]` of the projects).
- Validation errors are **400** (not FastAPI's 422): `{"error": "<field>: <msg>; ..."}`.
- A non-integer id in the path is a **404** `{"error": "Not Found"}`, as Flask's route converters gave.
- Unknown route 404 and wrong method 405 are `{"error": "Not Found" | "Method Not Allowed"}`.
- Duplicate row: 409 `{"error": "Record already exists"}`. Anything unexpected: 500 `{"error": "Internal Error"}`.

## Auth
- `POST /login`, form-encoded `username`, `password` -> `{"token": "<refresh token>"}`.
- `POST /refresh_token` with the token in `Authorization` -> `{"token": ...}`.
- Every other route (except `/health_check`, `/ready_check`, `PUT /global/users/reset-password`) needs
  `Authorization: Bearer <token>`. Missing: 401 `{"error": "Token not provided"}`. Not enough scope: 403.

## Pagination
- Paged lists return `{"items": [...], "page", "per_page", "total", "pages"}`; `?page=` and `?per_page=`
  (1-based, defaults 1 and 25 unless a route says otherwise). The project tasks list uses `tasks` in place of `items`.
- Paged responses have no response model in the spec yet (no new DTOs during the port); their items do
  where a route returns a list of DTOs. Ask under "Needs from nexus" if you need a typed page.

## Routing
- Collections answer on both `/x` and `/x/` (no redirects).

## Spec
- Served live at `/openapi.json`, docs at `/docs`.
- Committed at `nexus/api/openapi.json`, regenerated by `nexus/api/dump_openapi.py`
  (`python dump_openapi.py` from `nexus/api` with the env of `run_local_tests.sh`). Only routers already
  ported are in it; see HANDOVER.md for which.

## Local
- Tilt port-forward: nexus on `localhost:5002` (the webserver stays on 5000).
