# Support

This document explains where to go for help with the PHEMS Federated Node.

## Supported versions

| Version        | Supported          |
| -------------- | ------------------- |
| Latest release (`main`) | :white_check_mark: |
| Older releases | We do not support older releases, please upgrade where possible |

## Documentation

Start with the [README](README.md), which covers installation, deployment,
and basic usage. Additional guides may be linked there as they're added.

## Asking a question / getting help

- **GitHub Discussions** — for general questions, usage help, and ideas,
  please use the [Discussions](https://github.com/Aridhia-Open-Source/PHEMS_federated_node/discussions)
  tab. This keeps Q&A searchable for future users with the same question.
- **GitHub Issues** — if you've found a reproducible bug or want to request
  a feature, open an [issue](https://github.com/Aridhia-Open-Source/PHEMS_federated_node/issues)
  using the appropriate template. Please search existing issues first to
  avoid duplicates.

When reporting a problem, please include:

- The version/commit of the Federated Node you're running
- Your deployment environment (e.g. OS, container runtime, Kubernetes version if relevant)
- Steps to reproduce the issue
- What you expected to happen vs. what actually happened
- Relevant logs or error messages (with any sensitive data removed)

## Security issues

Please **do not** open a public issue for security vulnerabilities. See
[SECURITY.md](SECURITY.md) for how to report these responsibly.

## Contacting the team directly

For questions that aren't suited to a public issue or discussion (e.g.
partnership or deployment inquiries), you can reach the Aridhia Open Source
team at **opensource@aridhia.com**.

## Contributing

If you'd like to contribute a fix or improvement rather than just report a
problem, see [CONTRIBUTING.md](CONTRIBUTING.md).
